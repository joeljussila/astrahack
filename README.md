# Astra hackathon context

Planning and shared context for the September 8, 2026 Astra SF hackathon. This initial upload contains Markdown documents only. Implementation code is not included.

## Two project concepts

Both explore the same interaction: point at something, say “this,” and work with Astra to change a real editable design.

- [Interactive 3D design partner](PROJECT_3D.md): use an iPhone to point into a native Blender scene, then discuss and make spatial design changes with Astra.
- [Excalidraw design partner](PROJECT_EXCALIDRAW.md): use pointing and conversation to build and revise software architecture diagrams in a real Excalidraw canvas.

The working direction has favored 3D for its visual demo potential, with Excalidraw as a simpler alternative. These briefs support the team’s decision; they do not require building both for the final demo.
